## When adding images

For each input, document:

- Original filename
- Source URL or dataset citation
- Access date
- License or redistribution terms
- Any preprocessing already applied
- Whether the image is real astronomical data, simulated data, or an illustrative image

Do not claim that an image is observational or scientifically representative unless its provenance supports that claim.
